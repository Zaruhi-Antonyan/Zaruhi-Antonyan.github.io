# Zaruhi Antonyan — QA Portfolio

A responsive dark-themed portfolio website built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — responsive styles
- `script.js` — mobile navigation and footer year
- `assets/Zaruhi_Antonyan_QA_CV.pdf` — downloadable CV

## Preview locally
Open `index.html` in a browser. For a local development server, you can use VS Code with the Live Server extension.

## Publish for free with GitHub Pages
1. Create a GitHub repository named `Zaruhi-Antonyan.github.io` (the username in your CV is `Zaruhi-Antonyan`; confirm the account name is exactly the same).
2. Upload the contents of this folder to the repository root. `index.html` should be at the root, not inside another nested folder.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment settings, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for the deployment and visit `https://Zaruhi-Antonyan.github.io`.

If GitHub Pages doesn't accept the URL, check that the repository owner spelling and capitalization match your GitHub username. GitHub Pages URLs are case-insensitive in normal browser use.

## Before applying
- Review the contact details and CV download.
- Open each GitHub project link and verify it is public and current.
- Keep only claims you can confidently discuss in an interview.
- The skill meter bars are decorative design elements, not measured proficiency scores; consider removing them if you prefer to avoid visual ratings.
- This site uses Google Fonts; if the font service is unavailable, it falls back to system fonts.
