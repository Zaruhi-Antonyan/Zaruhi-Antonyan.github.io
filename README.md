# Zaruhi Antonyan — QA Portfolio

A responsive dark-themed portfolio website built with plain HTML, CSS, and JavaScript. Content and downloadable CV are aligned with the latest CV provided in October 2026.

## Files
- `index.html` — page content and structure
- `style.css` — responsive styles
- `script.js` — mobile navigation and footer year
- `assets/Zaruhi_Antonyan_QA_CV.pdf` — updated downloadable CV

## Preview locally
Open `index.html` in a browser. For a local development server, you can use VS Code with the Live Server extension.

## Publish an update to the existing GitHub Pages site
1. Extract this ZIP into a new folder.
2. Copy the contents of the extracted folder into your existing local portfolio folder, replacing the older files. Make sure the `assets` folder and updated PDF are included.
3. Open Git Bash in the local portfolio folder.
4. Run:

   ```bash
   git add .
   git status
   git commit -m "Update portfolio with latest CV"
   git push
   ```

5. Wait a few minutes, then refresh `https://Zaruhi-Antonyan.github.io`.

If this is a fresh local folder without the Git repository history, use the existing repository's local folder instead of running `git init` again.

## Before applying
- Review contact details and the CV download.
- Open each GitHub project link and verify that it is public and current.
- Keep only claims you can confidently discuss in an interview.
- The skill meter bars are decorative design elements, not measured proficiency scores.
- This site uses Google Fonts; if the font service is unavailable, it falls back to system fonts.
